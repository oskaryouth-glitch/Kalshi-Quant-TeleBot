# Permission request drafts

Nothing here is sent automatically. Edit and send them yourself if you want
to. Replace the bracketed parts. Keep the replies: when a platform grants
permission, record it in `config/sources.yaml` (`automated_collection:
authorized`, plus the date, scope and limits) before any collector is built.
